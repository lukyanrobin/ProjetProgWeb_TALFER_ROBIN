# Maquette du site essAI (wireframes)

Livrable demandé par l'énoncé (« maquette du site : wireframe, Miro… »). Ouvre **`index.html`** dans un navigateur pour voir toutes les planches.

| Fichier | Contenu |
|---|---|
| `00_plan_du_site.svg` | Arborescence : accueil (niveau 0) et 4 pages (niveau 1), avec leurs sections |
| `01_accueil_ordinateur.svg` | Accueil : accroche, démo animée sur téléphone, étapes, carrousel, intégrations, offres |
| `02_fonctionnalites_ordinateur.svg` | Fonctionnalités : dictée, reformulation, rangement, chatbot avec avatar, approfondissement et agents |
| `03_tarifs_ordinateur.svg` | Tarifs : bascule mensuel/annuel, 3 offres (prix de lancement), tableau comparatif, « Où va ton argent ? », FAQ |
| `04_a-propos_ordinateur.svg` | À propos : le problème, les engagements, l'équipe et le travail de chacun |
| `05_contact_ordinateur.svg` | Contact : formulaire validé en JS, liste d'attente |
| `06_toutes_les_pages_telephone.svg` | Les 5 pages en version téléphone (390 px), menu burger |

Sur chaque planche, les **pastilles numérotées** renvoient aux notes de droite, qui décrivent les interactions prévues en JavaScript.

Couleurs : vert forêt `#12271F`, crème `#FBFAF6`, sauge `#8FB3A0`, ambre `#E0A84F` (tirées du logo).

`generer_maquette.py` régénère les planches si on modifie la maquette : `python3 generer_maquette.py .`
